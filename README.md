# Deep Learning Exercises

A collection of hands-on deep learning projects and exercises completed while studying Data Science.

## Projects

### 🍎 Fruit Classification Using CNNs

A multi-class image classification project using Convolutional Neural Networks (CNNs) to classify five types of fruit:

- Apple
- Banana
- Mango
- Grape
- Pineapple

The project explores different approaches to improving image classification performance and reducing overfitting.

#### Techniques explored

- Convolutional Neural Networks (CNNs)
- Data preprocessing and normalization
- Data augmentation
- Batch Normalization
- Dropout regularization
- Early Stopping
- Training and validation analysis
- Deeper CNN architectures
- Transfer Learning using MobileNetV2
- Confusion matrix and classification evaluation
- Testing on unseen images

### 🐱 Cats vs Dogs CNN

A CNN-based image classification exercise for distinguishing between cats and dogs using image data.

### 🧠 Deep Neural Networks Exercise

Hands-on exercises exploring the fundamentals of neural networks and deep learning using Python and Jupyter notebooks.
